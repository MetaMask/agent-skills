# MetaMask Agent Wallet

This Antigravity (`agy`) plugin bundles the `metamask-agent-wallet` skill for the MetaMask Agent Wallet CLI (`mm` / `@metamask/agent-wallet`).

When the user asks about blockchain wallets, transactions, signing, transfers, balances, swaps, bridges, perps, prediction markets, DeFi earn, x402 / 402 Payment Required, calldata decoding, or any `mm` command, read `skills/metamask-agent-wallet/SKILL.md` and follow it. Do not invent `mm` flags.

Never install or upgrade `@metamask/agent-wallet` without asking the user first. Prefer `mm doctor` before the first wallet operation in a session.
